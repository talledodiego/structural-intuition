# 0003 — Italian/English localisation selected via URL

- **Status:** accepted
- **Date:** 2026-10-05

## Decision

Every applet is available in Italian and English. The language is read from the URL parameter `?lang=` (`it` default, `en`). Texts live in `strings.py`; technical terms follow `docs/glossary.md`.

## Reasons

- Courses are taught in both languages (e.g. Laboratorio di Progetto in Italian, Disaster in English).
- The project is public on GitHub and may interest teachers outside Italy.
- A URL parameter lets each course link directly to its language, without a visible switch.
- Planned from the first applet, the cost is low; retrofitting later is expensive.

## Consequences

- Text writing effort increases by roughly 30–50% (mostly review of the English draft).
- A test checks that every key exists in both languages.
- Details: `docs/i18n.md`.
